What this prototype does

  • ML-KEM-768 + HKDF-SHA256Creates a fresh encryption key for the receiver’s public key.
  • AES-256-GCMEncrypts contents and rejects changed packages.
  • Local processingNo file, private key, or password is sent to this site’s server.
  • Manual deliveryDownload and share the encrypted package yourself.
Limits

Anyone with the public key can make a package; sender identity is not verified. Confirm the public key fingerprint through another channel. The filename and approximate file size are visible in the package. A stolen private key can open earlier packages. This hackathon prototype has not had an independent security audit.

The existing Streamlit app remains in qshield 2/. Its password-protected PEM private keys are not imported by this browser version; use a browser backup generated here.
